# LightAudio Editor 0.2.0 Beta 5

## Changes

- Light mode now uses light track panels, controls, and inspector cards, with readable clip labels and waveforms. The existing Dark mode palette is preserved.
- Preferences now has a visible **System Default / Light / Dark** appearance control. Changes apply immediately and are remembered across launches.
- This release also includes the recent macOS editing and media improvements: clip and track automation editors, continuous looping, background autosave, independent Save As, cancellable imports, portable media collection, verified relinking, and custom export ranges.

## Installation

Download and extract `LightAudio-Editor-0.2.0-beta-5-ADHOC-UNNOTARIZED.zip`, then move **LightAudio Editor.app** to Applications. FFmpeg is bundled inside the app, so M4A, MP3, and FLAC export require no additional download or configuration. The encoder-source archive is provided for licensing compliance and is not needed to run the app.

This beta is ad-hoc signed and unnotarized. If macOS blocks the first launch, allow it under **System Settings > Privacy & Security**, or **System Preferences > Security & Privacy > General** on Catalina. Do not disable Gatekeeper globally.

## Compatibility

- Intel Macs: macOS Catalina 10.15 or later
- Apple silicon Macs: macOS Big Sur 11.0 or later
- Universal app: `x86_64` and `arm64`
